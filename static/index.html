接口地址与请求

        

        

          请求表头
          
        

        

        

          值支持 {{apiKey}}、{{model}} 等变量。敏感 token 建议写成
          Bearer {{apiKey}}，这样只保存在内存，不写入 data\store.json。
        


        
请求体模板（JSON）

        
        

          可用变量：{{prompt}} 完整提示词（系统+业务，单入参接口直接用这个）、
          {{system}} 系统提示词、{{user}} 用户提示词、
          {{messages}} 消息数组、{{model}}、{{apiKey}}、
          {{requestId}} 每次调用唯一 ID、{{max_tokens}}、{{temperature}}。
          占位符必须放在 JSON 字符串里，例如 "input": "{{user}}"；
          整个值只写一个占位符时，会替换成对应类型（数组/数字）。
        

        

          单入参接口：点「单入参 question 模板」会填入本机
          local-defaults.json 中的地址、路径、userId（未配置时使用占位值），
          以及 Content-Type / token / userId 表头、
          {"question": "{{prompt}}", "sessionId": "testuuid"}
          和返回路径 result.finalAnswer。token 保留原值，不会被覆盖。
        

        

          
          
          切换协议不会自动改模板
        


        
返回字段路径

        
        
        
        

          路径用点号分隔，支持数组下标：data.items[0].answer、
          choices.0.message.content。
